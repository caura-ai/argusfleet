# ArgusFleet Harness — Code Review Report

**Date:** 2026-05-30
**Scope:** `argusfleet` source — `harness/`, `experiments/`, `cli.py`, `configs/`, `scripts/`, `tests/` (≈4,300 LoC source + 1,535 LoC tests). Excludes `paper/` and `outputs/`.
**Method:** Multi-agent fan-out (11 module slices) → independent adversarial verification of every finding (refute-by-default) → dedup + ranked synthesis. 80 agents; 68 findings raised, **65 survived verification, 3 refuted**.

---

## 1. Executive Summary

The ArgusFleet harness is broadly sound and internally consistent: the four experiments run end-to-end, the test suite passes, and the production YAML configs match the published paper. The defects cluster into three recurring themes. **(a) Documentation drift** dominates: a product rename (agentfleetmem → argusfleet) left env-var docs reading a dead prefix, a stale module docstring claims experiments are unimplemented stubs, and several comments describe behavior the code never performs. **(b) Metric-validity gaps** in the experiment layer: `had_contradiction` and the with-contradiction latency split can never populate (detection is async), `completeness` and `depth_fidelity` collapse to the identical computation in provenance, and write/rate-limit failures silently deflate headline accuracy. **(c) A genuinely broken feature in the default path**: `run all --cleanup` is a no-op in the shipped (synthesized-tenant) mode, so repeated runs accumulate dedup state and 409. None of these threaten the system-under-test; the impact is on the *fidelity of the harness's own outputs* and on developer/operator workflows. No security issues, no data corruption. The single highest-value fixes are the cleanup no-op, the env-prefix mismatch, and the two provenance/contradiction metric collapses.

## Paper implications

Two code findings touch the published numbers:
- **B2** — §8.2 reports `completeness` and `depth-fidelity` as two independent `1.00`s, but they are the *same computation*; report them as one metric or note the dependence.
- **B7** — the propagation semaphore-across-sleep is the mechanism behind the paper's "time-to-visibility is an upper bound, confounded by probe scheduling" caveat; fixing it would yield a tighter, truer consistency window.
